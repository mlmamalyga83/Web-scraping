# Техническое задание — Парсер Habr

## 1. Цель

Написать скрипт на Python, который собирает preview-информацию со списковой
страницы habr.com, затем переходит в каждую статью, извлекает полный текст,
сверяет его с ключевыми словами и выводит результат в консоль.

## 2. Источник данных

**Выбранный источник:** `https://habr.com/ru/articles/`

Почему он, а не `/ru/feed/`:
- `/ru/feed/` — это персонализированная лента, где структура элементов
  может зависеть от куков и авторизации.
- `/ru/articles/` — статическая страница «все статьи подряд», всегда
  возвращает одинаковую структуру, подходит для парсинга без авторизации.

## 3. Preview — что собираем на списковой странице

Для каждой статьи на `/ru/articles/` нужно извлечь:

- **Заголовок** — внутри `<h2 class="tm-title tm-title_h2">`, текст во
  вложенном `<a class="tm-title__link"><span>...</span></a>`
- **Дата публикации** — из атрибута `datetime` у тега `<time>`
  (формат ISO 8601: `2026-11-26T09:02:05.000Z`)
- **Ссылка на полную статью** — атрибут `href` у `<a class="tm-title__link">`
  (относительная, нужен urljoin с https://habr.com)

Preview-текст (краткое описание) на этом этапе **не выводится** — он нужен
только для навигации в задании (чтобы понять, о чём статья).

**Структура HTML (один элемент списка):**
```html
<article class="tm-articles-list__item">
  <h2 class="tm-title tm-title_h2">
    <a class="tm-title__link" href="/ru/articles/123456/">
      <span>Заголовок статьи</span>
    </a>
  </h2>
  <a class="tm-article-datetime-published" href="...">
    <time datetime="2026-11-26T09:02:05.000Z">...</time>
  </a>
  <div class="article-formatted-body">
    ... preview-текст ...
  </div>
</article>
```

## 4. Ключевые слова

Задаются списком в коде:

```python
KEYWORDS = ['дизайн', 'фото', 'web', 'python']
```

Проверка — регистронезависимая.
Слово считается найденным, если оно встречается в тексте хотя бы один раз
(поиск подстроки через `in` — допустимо для учебной работы).

## 5. Что делаем с каждой статьёй

1. Из preview достаём ссылку на полную статью.
2. Отправляем GET-запрос с заголовками (User-Agent, Accept-Language).
3. Загружаем полный HTML статьи.
4. Извлекаем текст статьи из блока:
   ```html
   <div class="article-formatted-body article-formatted-body_version-2">
     <!-- текст статьи (SSR, не требует JS) -->
   </div>
   ```
   Селектор для BeautifulSoup: `.article-formatted-body.article-formatted-body_version-2`
5. Приводим к нижнему регистру, проверяем ключевые слова.
6. Если найдено совпадение — печатаем строку: `дата | заголовок | ссылка`

## 6. Формат вывода (консоль)

Только для статей, где ключевые слова найдены:

```
2026-11-26 | Как AI меняет дизайн | https://habr.com/ru/articles/123456/
2026-11-25 | Обзор PyCharm 2025.3 | https://habr.com/ru/articles/123457/
```

Дата берётся из `datetime` (ISO 8601), форматируется в `YYYY-MM-DD`.

Если ни одна статья не подошла — вывести: `Совпадений не найдено.`

## 7. Пагинация (сколько страниц парсить)

- Парсим **первые 2 страницы** списка (около 40-50 статей).
- URL страниц:
  - Страница 1: `https://habr.com/ru/articles/`
  - Страница 2: `https://habr.com/ru/articles/page2/`
- Ограничение 2 страницы — чтобы не нагружать сайт и не уйти в капчу.
- Если на странице нет статей — остановиться.

## 8. HTTP-заголовки и защита от блокировок

Обязательно передавать:

```python
headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...',
    'Accept-Language': 'ru-RU,ru;q=0.9,en;q=0.8'
}
```

Без User-Agent habr может вернуть 403 или пустой ответ.

## 9. Инструменты и библиотеки

- Python 3.10+
- `requests` — HTTP-запросы
- `beautifulsoup4` — парсинг HTML
- `time` — паузы между запросами
- `datetime` — обработка дат
- `urllib.parse` — сборка полных URL (urljoin)

## 10. Структура скрипта

```
parser.py
```

Функции:

### `fetch_page(url) -> str | None`
- GET-запрос с заголовками
- Проверка статуса (200)
- При ошибке — print("[WARN] ...") и return None

### `parse_articles_list(html) -> list[dict]`
- BeautifulSoup → найти все `<article class="tm-articles-list__item">`
- Для каждого: title, date, link
- Дата: `datetime.fromisoformat(time['datetime'].rstrip('Z'))`
- Формат вывода: `date.strftime('%Y-%m-%d')`
- Возвращает `[{'title': str, 'date': str, 'link': str}, ...]`

### `parse_full_text(html) -> str | None`
- BeautifulSoup → `.select_one('.article-formatted-body.article-formatted-body_version-2')`
- Если найден → `.get_text(strip=True)`
- Если не найден → None

### `check_keywords(text, keywords) -> bool`
- `text.lower()` → проверка `kw.lower() in text`

### `main()`
- Константы: BASE_URL, KEYWORDS, MAX_PAGES
- Цикл по страницам (1..MAX_PAGES)
- Для каждой статьи: fetch → parse_full_text → check_keywords → print
- Если совпадений 0 → "Совпадений не найдено."

## 11. Обработка ошибок

| Ситуация | Действие |
|---|---|
| Страница списка не загрузилась | Пропустить, вывести предупреждение |
| В preview нет даты/заголовка | Пропустить такую статью |
| Статья не загрузилась (404, 403) | Пропустить с предупреждением |
| Полный текст не найден | Пропустить, предупреждение |
| Сетевая ошибка (timeout, connection) | Пропустить, предупреждение |

Между запросами — `time.sleep(1)`.
