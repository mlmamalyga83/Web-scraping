# Habr Parser

Парсер статей с habr.com с фильтрацией по ключевым словам.

## Описание

Скрипт собирает preview статей с https://habr.com/ru/articles/, переходит в каждую статью, извлекает полный текст и проверяет его на наличие ключевых слов. Статьи, в которых найдены совпадения, выводятся в консоль.

## Ключевые слова

По умолчанию: `['дизайн', 'фото', 'web', 'python']`

Можно изменить в коде (переменная `KEYWORDS`).

## Требования

- Python 3.10+
- requests
- beautifulsoup4

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python parser.py
```

## Пример вывода

```
2026-11-26 | Как мы перестали вручную приклеивать кастрюли к кухне | https://habr.com/ru/companies/X5Tech/articles/1108268/
2026-11-26 | Итак, вы создали виртуальную машину: что дальше? | https://habr.com/ru/companies/rubytech/articles/1112576/
```

## Параметры

- `MAX_PAGES = 2` — количество страниц для парсинга
- `DELAY = 1` — задержка между запросами (сек)
